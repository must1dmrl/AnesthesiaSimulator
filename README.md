# Anesthesia Simulator (prototype v0.1)

A Kotlin + Jetpack Compose educational anesthesia scenario prototype.

## Build on an Android tablet

1. Create a GitHub repository and upload the contents of this project.
2. Open the repository's **Actions** tab.
3. Select **Build Android APK** and tap **Run workflow** (or push to `main`).
4. When the workflow completes, open its run and download the `AnesthesiaSimulator-debug` artifact.
5. Extract the ZIP and install `app-debug.apk` on your tablet.

The first prototype uses a custom-drawn operating-room scene as a lightweight placeholder. It is **not yet a true interactive 3D scene**. The next development step is integrating a 3D engine and real 3D assets.

Educational prototype only. Not for clinical use or real patient-care decisions.
